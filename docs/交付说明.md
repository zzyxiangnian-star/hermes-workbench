# 工作台 · 安装和使用说明

> 给客户各部门试用时用。每台电脑各装一份，数据存在本机，不需要登录。

## 一、它是什么

工作台是装在 Hermes 桌面版里的一个插件，左上角“会话 | 机器人 | 工作台”里点“工作台”进入。分两块：

| 工作台 | 分页 | 做什么 |
|---|---|---|
| 电商 | 经营 | 各店铺销售、投放的日报和趋势，投放异常提醒 |
| | 商品 | 导入商品表后自动检查低于底价、库存不足、跨店价差、缺活动，逐条处理 |
| | 客户 | 订单按手机号建档、会员分层、批量跟进话术（人工复制去发）、B 端询盘和报价单 |
| | 安装 | 需要上门安装的订单变成工单：预约、改约、异常、完工，复制预约通知 |
| 品牌活动 | 活动 | 活动日历、目标和预算、任务清单、复盘 |
| | 内容 | 写稿、违禁词检查、送审、批注、退回、发布记录、版本对比 |
| | 设计 | 设计需求单、候选稿、图上批注、定稿，定稿进素材库 |
| | 资料 | 商品资料卡、品牌规范、违禁词表 |
| | 视频 | 短视频分镜、配音、审核、初剪包（素材 + 字幕 + 时间线），上传成片 |

另有四个助手 Bot（电商、品牌、设计、视频），在“机器人”里和它们对话，它们能查工作台的数据、写草稿和备注。

**几条规矩（系统本身就这样设计）**
- 不登录任何电商平台，不改价、不改出价、不暂停投放、不报名活动、不代发内容。
- 不会自动给顾客发任何消息。跟进话术、预约通知都是人复制后自己发。
- AI 只写草稿和备注；送审、审核、发布、定稿、完工都由人点。
- 顾客手机号、地址交给 AI 之前会打码。

## 二、安装（每台电脑做一次）

需要：Windows 10/11，已装好 Hermes 桌面版，Python 3.11 或更新版本（https://www.python.org/downloads/ ，安装时勾选 “Add python.exe to PATH”）。

1. 把交付包（`工作台-版本号-日期.zip`）解压到一个固定位置，例如 `D:\`，得到 `D:\工作台\`。里面有 `server\`（后端）、`plugin.js`（插件）、`bots\`（四个助手的配方）和 `版本.txt`。
2. **启动后端**：双击 `server\scripts\start.bat`。第一次会自动建环境、装依赖，需要联网，几分钟。看到“工作台后端已启动：http://127.0.0.1:8000”就好了。这个黑窗口不要关，关了工作台就连不上。
3. **装插件**：把 `plugin.js` 放到 `%USERPROFILE%\.hermes\desktop-plugins\hermes-workbench\` 下（没有这个文件夹就新建；如果 Hermes 改过数据目录 `HERMES_HOME`，放到那个目录下的 `desktop-plugins\hermes-workbench\`），重启 Hermes。在 Hermes 设置的“功能（Capabilities）→ 插件（Plugins）”里能看到“工作台”。
4. **建助手 Bot**（用哪个建哪个）：在 Hermes 的“机器人”里新建，从 default 克隆，名字建议用 `bot-ecommerce`、`bot-brand`、`bot-design`、`bot-video`；把 `bots\<助手>\SOUL.md` 放进这个 Bot 的目录，把同目录 `config.yaml` 里的**每一段**合并进 Bot 的 `config.yaml`。步骤见 `bots\README.md`。

想先看看效果：双击 `server\scripts\demo.bat`，会用一套假数据启动（不碰正式数据），看完关掉窗口，再用 `start.bat` 启动正式的。

## 三、日常使用

- **每天开机**：先双击 `start.bat`，再打开 Hermes。
- **导入数据**：在商品、安装、客户页点“导入”，选平台后台导出的 Excel / CSV。认不出的行会列出原因，其余照常导入。
- **自动导入（可选）**：建一个报表文件夹，每个店铺一个子文件夹（名字和工作台里的店铺名一字不差），运营把导出的表扔进去，每 10 分钟自动导入。设置方法：把 `server\scripts\env.example.bat` 复制成 `env.bat`，填上 `WB_IMPORT_DIR`，重启后端。
- **早报**：每天 08:30 自动检查商品和投放规则并生成日报。要推到飞书或企业微信群，在 `env.bat` 里填 webhook 地址（地址是机密，不要发到群里）。
- **左栏数字**：商品 = 未处理问题，客户 = 未关闭询盘，安装 = 待预约加异常，活动 = 进行中，内容 = 送审中，设计 = 待接单和待评审，视频 = 待审核。

## 四、数据和备份

所有数据都在本机：

| 内容 | 位置 |
|---|---|
| 数据库 | `server\data\workbench.db` |
| 设计稿、素材、配音 | `server\data\assets\`（`env.bat` 里 `WB_ASSET_DIR` 可改） |
| 你自己的设置 | `server\scripts\env.bat` |

**自动备份**：后端开着时每天 12:30 自动备份一次，不用停服务。备份放在 `server\data\backups\`：
- `数据库\` 里是数据库快照，文件名带日期时间，只留最近 14 份；
- `素材\` 里是设计稿、素材、配音的副本，每次只复制新增的。

**强烈建议**把备份放到另一块硬盘或网盘同步文件夹：在 `env.bat` 里写 `set WB_BACKUP_DIR=E:\工作台备份`，重启后端。时间和份数用 `WB_BACKUP_AT`、`WB_BACKUP_KEEP` 改。

**手动备份**：双击 `server\scripts\backup.bat`，马上备份一次（升级前先点一下）。`env.bat` 自己备份一份到别处即可，它很少改。

客户分层的天数（新客 30 天、沉睡 90 天、询盘 7 天没跟进）和报价单有效期（15 天）也在 `env.bat` 里改：`WB_NEW_CUSTOMER_DAYS`、`WB_DORMANT_DAYS`、`WB_INQUIRY_STALE_DAYS`、`WB_QUOTE_VALID_DAYS`，改完重启后端。

**恢复**：关掉后端窗口，把最新的数据库快照复制回 `server\data\`，改名为 `workbench.db`（覆盖原来的）；把 `素材\` 里的文件复制回素材目录；再双击 `start.bat`。

不同电脑之间数据不互通。要把一台电脑的数据搬到另一台，照备份方法整份复制过去。

## 五、升级

拿到新版交付包后：
1. 双击 `server\scripts\backup.bat` 备份一次；
2. 关掉后端窗口；
3. 用新的 `server\` 覆盖旧的（`data\` 文件夹和 `scripts\env.bat` 不要删）；
4. 换上新的 `plugin.js`，重启 Hermes；
5. 双击 `start.bat`。数据库会自动升级，不用手动处理。

**看当前版本**：浏览器打开 http://127.0.0.1:8000/api/health ，`version` 就是后端版本；交付包里的 `版本.txt` 写了打包日期和插件校验码。

## 六、常见问题

| 现象 | 处理 |
|---|---|
| 工作台页面显示“没有连上工作台服务” | 后端没开。双击 `start.bat`，再点页面上的“重试”。 |
| `start.bat` 提示没找到 Python | 装 Python 3.11 或更新版本，安装时勾选 Add to PATH，再双击一次。 |
| `start.bat` 提示依赖安装失败 | 检查网络后重试。装过一次以后没网也能启动。 |
| 黑窗口最后一行停在数据库升级，像卡住了 | 等几秒，出现“Uvicorn running on http://127.0.0.1:8000”就是好了。 |
| 助手说“工作台后端没有启动” | 同第一条。 |
| 助手说某件事做不到，请到工作台里操作 | 正常。改状态、审核、发布、改价等都只能人在页面上点。 |
| 端口 8000 被占用 | 关掉另一个 `start.bat` 窗口，或重启电脑。 |

## 七、所有设置项（写在 `server\scripts\env.bat` 里，改完重启后端）

| 设置 | 默认 | 说明 |
|---|---|---|
| `WB_IMPORT_DIR`、`WB_IMPORT_EVERY` | 不启用、10 分钟 | 报表文件夹自动导入 |
| `WB_DAILY_AT` | 08:30 | 早报时间 |
| `WB_FEISHU_WEBHOOK`、`WB_WECOM_WEBHOOK` | 空 | 早报推送地址（机密） |
| `WB_ASSET_DIR`、`WB_ASSET_MAX_MB` | `server\data\assets`、50 | 素材位置和单个文件上限 |
| `WB_AI_IMAGE_DIRS` | Hermes 数据目录 | 助手生成的图片、配音放在哪，工作台只从这些目录读 |
| `WB_BACKUP_DIR`、`WB_BACKUP_AT`、`WB_BACKUP_KEEP` | `server\data\backups`、12:30、14 | 备份 |
| `WB_NEW_CUSTOMER_DAYS`、`WB_DORMANT_DAYS`、`WB_INQUIRY_STALE_DAYS`、`WB_QUOTE_VALID_DAYS` | 30、90、7、15 | 客户分层天数和报价有效期 |
| `WORKBENCH_DATABASE_URL` | `server\data\workbench.db` | 换数据库位置，一般不用改 |
| `WB_NULL_ORIGIN` | 只放行 Hermes 桌面版 | 工作台在 Hermes 里一直连不上、后端日志是 403 时临时设成 `any`，并联系我们 |
| `WB_ALLOWED_HOSTS`、`WB_ALLOWED_ORIGINS` | 本机 | 一般不用改 |
| `WB_SCHEDULER` | on | `off` 关掉早报、自动导入和自动备份 |

## 附：怎么打交付包（我们内部用）

1. `cd plugin`，`node build.mjs`（需要 Hermes 源码，`HERMES_SRC` 指过去）。
2. 回到仓库根目录，`python tools/package.py`，在 `dist\` 下得到 `工作台-<版本>-<日期>.zip`。
3. 版本号改 `server/app/__init__.py` 的 `__version__`（同时改 `server/pyproject.toml`、`plugin/package.json`）。

脚本只打包仓库里登记过的文件，`env.bat`、数据库、`.venv`、素材不会被带进去；`.bat` 统一转成 Windows 换行。
