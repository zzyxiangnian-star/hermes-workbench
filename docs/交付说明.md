# 工作台 · 安装和使用说明（草稿）

> 给客户各部门试用时用。每台电脑各装一份，数据存在本机，不需要登录。还在完善，设计页、视频页、剪映草稿做完后补上。

## 一、它是什么

工作台是装在 Hermes 桌面版里的一个插件，左上角“会话 | 机器人 | 工作台”里点“工作台”进入。分两块：

| 工作台 | 分页 | 做什么 |
|---|---|---|
| 电商 | 经营 | 各店铺销售、投放的日报和趋势，投放异常提醒 |
| | 商品 | 导入商品表后自动检查低于底价、库存不足、跨店价差、缺活动，逐条处理 |
| | 客户 | 订单按手机号建档、会员分层、批量跟进话术（人工复制去发）、B 端询盘和报价单 |
| | 安装 | 需要上门安装的订单变成工单：预约、改约、异常、完工，复制预约通知 |
| 品牌活动 | 活动 | 活动日历、目标和预算、任务清单、复盘 |
| | 内容 | 写稿、违禁词检查、送审、批注、退回、发布记录、版本对比 |
| | 设计 | 设计需求单、候选稿、图上批注、定稿（制作中） |
| | 资料 | 商品资料卡、品牌规范、违禁词表 |
| | 视频 | 短视频分镜、配音、审核、初剪包（制作中） |

另有四个助手 Bot（电商、品牌、设计、视频），在“机器人”里和它们对话，它们能查工作台的数据、写草稿和备注。

**几条规矩（系统本身就这样设计）**
- 不登录任何电商平台，不改价、不改出价、不暂停投放、不报名活动、不代发内容。
- 不会自动给顾客发任何消息。跟进话术、预约通知都是人复制后自己发。
- AI 只写草稿和备注；送审、审核、发布、定稿、完工都由人点。
- 顾客手机号、地址交给 AI 之前会打码。

## 二、安装（每台电脑做一次）

需要：Windows 10/11，已装好 Hermes 桌面版，Python 3.11 或 3.12（https://www.python.org/downloads/ ，安装时勾选 “Add python.exe to PATH”）。

1. 把交付包（`工作台-版本号-日期.zip`）解压到一个固定位置，例如 `D:\`，得到 `D:\工作台\`。里面有 `server\`（后端）、`plugin.js`（插件）、`bots\`（四个助手的配方）和 `版本.txt`。
2. **启动后端**：双击 `server\scripts\start.bat`。第一次会自动建环境、装依赖，需要联网，几分钟。看到“工作台后端已启动：http://127.0.0.1:8000”就好了。这个黑窗口不要关，关了工作台就连不上。
3. **装插件**：把 `plugin.js` 放到 `%USERPROFILE%\.hermes\desktop-plugins\hermes-workbench\` 下（没有这个文件夹就新建），重启 Hermes。设置 → 插件里能看到“工作台”。
4. **建助手 Bot**（用哪个建哪个）：在 Hermes 的“机器人”里新建，从 default 克隆；把 `bots\<助手名>\SOUL.md` 放进这个 Bot 的目录，把同目录 `config.yaml` 的内容合并进 Bot 的 `config.yaml`。具体见各助手目录里的 `README.md`。

想先看看效果：双击 `server\scripts\demo.bat`，会用一套假数据启动（不碰正式数据），看完关掉窗口，再用 `start.bat` 启动正式的。

## 三、日常使用

- **每天开机**：先双击 `start.bat`，再打开 Hermes。
- **导入数据**：在商品、安装、客户页点“导入”，选平台后台导出的 Excel / CSV。认不出的行会列出原因，其余照常导入。
- **自动导入（可选）**：建一个报表文件夹，每个店铺一个子文件夹（名字和工作台里的店铺名一字不差），运营把导出的表扔进去，每 10 分钟自动导入。设置方法：把 `server\scripts\env.example.bat` 复制成 `env.bat`，填上 `WB_IMPORT_DIR`，重启后端。
- **早报**：每天 08:30 自动检查商品和投放规则并生成日报。要推到飞书或企业微信群，在 `env.bat` 里填 webhook 地址（地址是机密，不要发到群里）。
- **左栏数字**：商品 = 未处理问题，客户 = 未关闭询盘，安装 = 待预约加异常，内容 = 送审中。

## 四、数据和备份

所有数据都在本机：

| 内容 | 位置 |
|---|---|
| 数据库 | `server\data\workbench.db` |
| 设计稿、素材、配音 | `server\data\assets\`（`env.bat` 里 `WB_ASSET_DIR` 可改） |
| 你自己的设置 | `server\scripts\env.bat` |

**备份**：先关掉后端黑窗口，再把上面三样复制到别处（U 盘或网盘）。建议每周一次。恢复时放回原位置再启动。

不同电脑之间数据不互通。要把一台电脑的数据搬到另一台，照备份方法整份复制过去。

## 五、升级

拿到新版交付包后：关掉后端窗口 → 用新的 `server\` 覆盖旧的（`data\` 文件夹和 `scripts\env.bat` 不要删）→ 换上新的 `plugin.js` → 双击 `start.bat`。数据库会自动升级，不用手动处理。升级前先做一次备份。

**看当前版本**：浏览器打开 http://127.0.0.1:8000/api/health ，`version` 就是后端版本；交付包里的 `版本.txt` 写了打包日期和插件校验码。

## 六、常见问题

| 现象 | 处理 |
|---|---|
| 工作台页面显示“没有连上工作台服务” | 后端没开。双击 `start.bat`，再点页面上的“重试”。 |
| `start.bat` 提示没找到 Python | 装 Python 3.11 或 3.12，安装时勾选 Add to PATH，再双击一次。 |
| `start.bat` 提示依赖安装失败 | 检查网络后重试。装过一次以后没网也能启动。 |
| 黑窗口最后一行停在数据库升级，像卡住了 | 等几秒，出现“Uvicorn running on http://127.0.0.1:8000”就是好了。 |
| 助手说“工作台后端没有启动” | 同第一条。 |
| 助手说某件事做不到，请到工作台里操作 | 正常。改状态、审核、发布、改价等都只能人在页面上点。 |
| 端口 8000 被占用 | 关掉另一个 `start.bat` 窗口，或重启电脑。 |

## 附：怎么打交付包（我们内部用）

1. `cd plugin`，`node build.mjs`（需要 Hermes 源码，`HERMES_SRC` 指过去）。
2. 回到仓库根目录，`python tools/package.py`，在 `dist\` 下得到 `工作台-<版本>-<日期>.zip`。
3. 版本号改 `server/app/__init__.py` 的 `__version__`（同时改 `server/pyproject.toml`、`plugin/package.json`）。

脚本只打包仓库里登记过的文件，`env.bat`、数据库、`.venv`、素材不会被带进去；`.bat` 统一转成 Windows 换行。
