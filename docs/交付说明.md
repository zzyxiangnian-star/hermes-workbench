# 工作台 · 安装和使用说明

> 给客户各部门试用时用。每台电脑各装一份，数据存在本机，不需要登录。

## 一、它是什么

工作台是装在 Hermes 桌面版里的一个插件，左上角“会话 | 机器人 | 工作台”里点“工作台”进入。分两块：

| 工作台 | 分页 | 做什么 |
|---|---|---|
| 电商 | 经营 | 各店铺销售、投放的日报和趋势，投放异常提醒 |
| | 商品 | 导入商品表后自动检查低于底价、库存不足、跨店价差、缺活动，逐条处理 |
| | 客户 | 订单按手机号建档、会员分层、批量跟进话术（人工复制去发）、B 端询盘和报价单 |
| | 安装 | 需要上门安装的订单变成工单：预约、改约、异常、完工，复制预约通知 |
| 品牌活动 | 活动 | 活动日历、目标和预算、任务清单、复盘 |
| | 内容 | 写稿、违禁词检查、送审、批注、退回、发布记录、版本对比 |
| | 设计 | 设计需求单、候选稿、图上批注、定稿，定稿进素材库 |
| | 资料 | 商品资料卡、品牌规范、违禁词表 |
| | 视频 | 短视频分镜、配音、审核、初剪包（素材 + 字幕 + 时间线），上传成片 |

另有四个助手 Bot（电商、品牌、设计、视频），在“机器人”里和它们对话，它们能查工作台的数据、写草稿和备注。

**几条规矩（系统本身就这样设计）**
- 不登录任何电商平台，不改价、不改出价、不暂停投放、不报名活动、不代发内容。
- 不会自动给顾客发任何消息。跟进话术、预约通知都是人复制后自己发。
- AI 只写草稿和备注；送审、审核、发布、定稿、完工都由人点。
- 顾客手机号、地址交给 AI 之前会打码。

## 二、安装（每台电脑做一次，三种方法任选一种）

需要：已装好 Hermes 桌面版；电脑能联网（第一次启动要下载后端依赖，几分钟）。

**方法 1：让 Hermes 自己装（最省事）**
在 Hermes 对话里说：

> 帮我安装这个插件并启用：`hermes plugins install zzyxiangnian-star/hermes-workbench --enable --yes-deps`，装好后启用它的 Desktop 部分。

**方法 2：在 Hermes 里点**
Capabilities → Plugins → 右上角 “Install from Git”，填 `zzyxiangnian-star/hermes-workbench`，安装时勾上 Agent 和 Desktop 两部分。

**方法 3：下载安装包双击（不方便用 Git 时）**
需要 Python 3.11 或更新版本（https://www.python.org/downloads/ ，安装时勾选 “Add python.exe to PATH”）。
1. 下载 `工作台-版本号-日期.zip`，解压到任意位置；
2. 双击里面的 `安装.bat`。它会自己找到 Hermes 实际用的数据目录（`HERMES_HOME`，或 `%LOCALAPPDATA%\hermes`，或 `%USERPROFILE%\.hermes`），旧版先备份，再装新版，桌面放两个快捷方式“工作台后端”“工作台演示”，最后用演示数据把后端启动起来；
3. 装完解压出来的文件夹可以删掉。

**装完以后（三种方法都一样）**
1. 从右下角托盘**完全退出** Hermes，再重新打开；
2. Capabilities → Plugins 里找到“工作台”，确认 **Agent** 和 **Desktop** 两个开关都是开的；
3. 左上角“会话 | 机器人 | 工作台”点“工作台”。第一次会显示“没有连上工作台服务”，点 **启动工作台**（正式数据）或 **用演示数据启动**（假数据，看效果用）。第一次要装依赖，等几分钟会自动进去。

**建助手 Bot**（用哪个建哪个）：在 Hermes 的“机器人”里新建，从 default 克隆，名字建议用 `bot-ecommerce`、`bot-brand`、`bot-design`、`bot-video`；把 `bots\<助手>\SOUL.md` 放进这个 Bot 的目录，把同目录 `config.yaml` 里的**每一段**合并进 Bot 的 `config.yaml`。步骤见 `bots\README.md`。

## 三、日常使用

- **每天开机**：打开 Hermes 进工作台，没连上就点“启动工作台”。也可以在对话里说“启动工作台”，或双击桌面“工作台后端”。后端在后台运行，没有黑窗口。
- **导入数据**：在商品、安装、客户页点“导入”，选平台后台导出的 Excel / CSV。认不出的行会列出原因，其余照常导入。
- **自动导入（可选）**：建一个报表文件夹，每个店铺一个子文件夹（名字和工作台里的店铺名一字不差），运营把导出的表扔进去，每 10 分钟自动导入。设置方法：在 `settings.env` 里写 `WB_IMPORT_DIR=D:\工作台报表`，重启后端（见第四节）。
- **早报**：每天 08:30 自动检查商品和投放规则并生成日报。要推到飞书或企业微信群，在 `settings.env` 里填 webhook 地址（地址是机密，不要发到群里）。
- **左栏数字**：经营 = 未处理投放提醒，商品 = 未处理问题，客户 = 未关闭询盘，安装 = 待预约加异常，活动 = 进行中，内容 = 送审中，设计 = 待接单和待评审，视频 = 待审核。

## 四、数据和备份

所有数据都在本机，放在 Hermes 数据目录下的 `workbench\` 里（一般是 `%LOCALAPPDATA%\hermes\workbench\`；在对话里问“工作台数据在哪”或运行 `hermes workbench where` 能查到）。升级、重装插件都不会碰它：

| 内容 | 位置（都在 `workbench\` 下） |
|---|---|
| 数据库 | `data\workbench.db`（演示数据是 `data\demo.db`，每次演示重建） |
| 设计稿、素材、配音 | `data\assets\` |
| 自动备份 | `data\backups\` |
| 你自己的设置 | `settings.env` |
| 后端日志 | `backend.log` |
| 后端用的 Python 环境 | `venv\`（坏了可以整个删掉，下次启动会重建） |
| 安装时备份的旧版 | `backup\` |

**改设置**：用记事本打开 `settings.env`，去掉对应行开头的 `#` 再改值，一行一个，例如 `WB_BACKUP_DIR=E:\工作台备份`。改完让后端重启：对话里说“重启工作台后端”，或 `hermes workbench stop` 再 `start`。

**自动备份**：后端开着时每天 12:30 自动备份一次，不用停服务：
- `数据库\` 里是数据库快照，文件名带日期时间，只留最近 14 份；
- `素材\` 里是设计稿、素材、配音的副本，每次只复制新增的。

**强烈建议**把备份放到另一块硬盘或网盘同步文件夹：`settings.env` 里写 `WB_BACKUP_DIR=E:\工作台备份`。时间和份数用 `WB_BACKUP_AT`、`WB_BACKUP_KEEP` 改。`settings.env` 自己备份一份到别处即可，它很少改。

客户分层的天数（新客 30 天、沉睡 90 天、询盘 7 天没跟进）和报价单有效期（15 天）也在 `settings.env` 里改：`WB_NEW_CUSTOMER_DAYS`、`WB_DORMANT_DAYS`、`WB_INQUIRY_STALE_DAYS`、`WB_QUOTE_VALID_DAYS`。

**恢复**：停掉后端（`hermes workbench stop`），把最新的数据库快照复制到 `workbench\data\`，改名为 `workbench.db`（覆盖原来的）；把 `素材\` 里的文件复制回 `data\assets\`；再启动。

不同电脑之间数据不互通。要把一台电脑的数据搬到另一台，把整个 `workbench\data\` 和 `settings.env` 复制过去。

**从 0.10.0 及以前升级**：以前数据放在解压目录的 `server\data\`（比如 `D:\工作台\server\data\`）。用 `安装.bat` 升级时，如果新位置还没有正式数据库，会自动把 `D:\工作台\server\data\workbench.db` 和素材**复制**过来（原文件不动）。不在 `D:\工作台` 的，手动复制到 `workbench\data\`。以前的 `env.bat` 设置照抄到 `settings.env`（去掉开头的 `set `）。旧的 `start.bat` / `demo.bat` 黑窗口别再开，会占住端口。

## 五、升级

- 用方法 1、2 装的：在对话里说“升级工作台插件”，或运行 `hermes plugins update hermes-workbench`；
- 用安装包装的：下载新包，解压，双击 `安装.bat`。

然后完全退出 Hermes 再打开，点“启动工作台”。数据库会自动升级，不用手动处理。

## 六、常见问题

| 现象 | 处理 |
|---|---|
| 工作台页面显示“没有连上工作台服务” | 点“启动工作台”。没有这个按钮：到 Capabilities → Plugins 把“工作台”的 Agent 开关打开；或双击桌面“工作台后端”。 |
| 点了启动，提示失败 | 页面上会写原因，详细的在 `workbench\backend.log`。最常见是没联网（第一次要下载依赖）。也可以把原因发给 Hermes 让它帮忙看。 |
| 端口 8000 被占用 | 以前的 `start.bat` / `demo.bat` 黑窗口还开着就关掉；否则重启电脑。 |
| 左上角没有“工作台” | Capabilities → Plugins 里把“工作台”的 Desktop 开关打开，再完全退出 Hermes 重开。 |
| 看到的还是旧界面 | 用 `安装.bat` 再装一次，它会把所有数据目录里的旧插件换掉；然后完全退出 Hermes 重开。 |
| 助手说“工作台后端没有启动” | 同第一条。 |
| 助手说某件事做不到，请到工作台里操作 | 正常。改状态、审核、发布、改价等都只能人在页面上点。 |

## 七、所有设置项（写在 `workbench\settings.env` 里，一行一个 KEY=VALUE，改完重启后端）

| 设置 | 默认 | 说明 |
|---|---|---|
| `WB_IMPORT_DIR`、`WB_IMPORT_EVERY` | 不启用、10 分钟 | 报表文件夹自动导入 |
| `WB_DAILY_AT` | 08:30 | 早报时间 |
| `WB_FEISHU_WEBHOOK`、`WB_WECOM_WEBHOOK` | 空 | 早报推送地址（机密） |
| `WB_ASSET_DIR`、`WB_ASSET_MAX_MB` | `workbench\data\assets`、50 | 素材位置和单个文件上限 |
| `WB_AI_IMAGE_DIRS` | Hermes 数据目录 | 助手生成的图片、配音放在哪，工作台只从这些目录读 |
| `WB_BACKUP_DIR`、`WB_BACKUP_AT`、`WB_BACKUP_KEEP` | `workbench\data\backups`、12:30、14 | 备份 |
| `WB_NEW_CUSTOMER_DAYS`、`WB_DORMANT_DAYS`、`WB_INQUIRY_STALE_DAYS`、`WB_QUOTE_VALID_DAYS` | 30、90、7、15 | 客户分层天数和报价有效期 |
| `WB_NULL_ORIGIN` | 只放行 Hermes 桌面版 | 工作台在 Hermes 里一直连不上、后端日志是 403 时临时设成 `any`，并联系我们 |
| `WB_ALLOWED_HOSTS`、`WB_ALLOWED_ORIGINS` | 本机 | 一般不用改 |
| `WB_SCHEDULER` | on | `off` 关掉早报、自动导入和自动备份 |

剪映草稿（直接生成剪映工程）还在做，做好后补到视频页说明里。

## 附：怎么打交付包（我们内部用）

1. `cd plugin`，`node build.mjs`（需要 Hermes 源码，`HERMES_SRC` 指过去）。
2. 回到仓库根目录，`python tools/package.py`：更新 `desktop/plugin.js`（方法 1、2 装的就是它，要提交），并在 `dist\` 下得到 `工作台-<版本>-<日期>.zip`。
3. 版本号改 `server/app/__init__.py` 的 `__version__`（同时改 `server/pyproject.toml`、`plugin/package.json`、根目录 `plugin.yaml`）。

仓库根目录本身就是 Hermes 插件包：`plugin.yaml` + `__init__.py`（注册 `workbench_backend` 工具、`hermes workbench` 命令、`workbench` 技能）+ `desktop/plugin.js`（界面）+ `dashboard/plugin_api.py`（界面上“启动工作台”按钮调用的接口）+ `workbench_ctl.py`（找数据目录、建 Python 环境、启动停止后端，只用标准库）+ `server/`（后端）。

脚本只打包仓库里登记过的文件，`env.bat`、数据库、`.venv`、素材不会被带进去；`.bat` 统一转成 Windows 换行。
