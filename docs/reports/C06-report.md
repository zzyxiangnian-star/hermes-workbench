# C06 完成报告：报表文件夹自动导入、演示数据、一键启动

做的人：Claude（用户说“继续”）。目的：让客户演示和日常使用都不用敲命令。

## 做了什么

- **报表文件夹自动导入**（`app/folder_import.py`）：方案里写的“运营每天把导出的报表放进指定文件夹，系统自动读”。每个店铺一个子文件夹，按表头自动认出商品 / 经营 / 投放表；定时扫描（默认 10 分钟），早报前也先扫一遍；成功的移到“已导入”、失败的移到“失败”并写原因；刚放进去 10 秒内的不动。接口：`GET /api/import/folder`、`POST /api/import/folder/scan`。
- **演示数据**（`app/demo.py`，`workbench-demo`）：一条命令生成一整套假数据（4 店铺、30 天经营投放、商品问题、投放提醒、品牌规范、资料卡、3 个活动、4 篇不同状态的稿件），日期跟着今天走，固定随机种子。走的是工作台自己的接口，规则和提醒都会真实跑出来。
- **Windows 一键启动**：`server/scripts/start.bat`（正式）、`demo.bat`（演示库）、`env.example.bat`（设置模板）。第一次自动建虚拟环境、装依赖；没联网时用已装好的版本。
- `.gitignore` 加了 `server/.venv/`、`server/data/*.db`、`server/scripts/env.bat`。
- 文档：`server/README.md` 重写开头，`docs/CONTRACT-products.md` 加“报表文件夹”一节；W05 卡里顺带让商品页导入弹窗显示文件夹状态和“立即导入”。
