# C10 完成报告：短视频后端和视频助手

做的人：Claude（用户说“继续”）。第三期的第一块：短视频（脚本、配音、剪映初剪）。

## 做了什么

- **视频项目和分镜**：每镜写画面说明、口播、字幕（默认同口播，可以单独改或不要）、时长，配画面（图片或视频，可直接用素材库里设计页的定稿）和配音；背景音乐单独传。有配音时，这一镜自动拉长到和配音一样长（MP3、WAV 能读出时长）。
- **审核**：写脚本 → 送审（标题、口播、字幕先过违禁词）→ 通过 / 退回（必须写意见）；送审后脚本锁定，要改先撤回或被退回。每步记处理记录。
- **初剪包**：审核通过后下载 zip：素材按镜号命名（01_画面.png、01_配音.wav…）、字幕 SRT（按标点切成每条 16 字以内，时间按字数分）、分镜表 CSV、时间线 JSON 和剪映里怎么摆的说明。剪辑精修后把成片传回来，项目完成，成片进素材库。
- **视频助手 Bot**（`bots/video-assistant/`）：查资料卡写分镜（先过违禁词），存成新脚本；用 Hermes 自带的 `text_to_speech` 配音（默认 Edge TTS，免费）、用生图或素材库的图配画面，交回对应镜号。只能改写脚本中的项目，不能送审、通过、交成片。
- **迁移 c10**：新表 video_projects、video_shots，素材多一种 `material`（视频用的画面和配音，不进素材库列表）；与模型比对一致，升级、降级再升级都验证过。
- **演示数据**：2 个项目（“木屿夏凉被 15 秒种草”已通过，可下载初剪包；“星年空调省电口播”写脚本中），配音是静音占位。
- 文档：新增 `docs/CONTRACT-video.md`，更新 `CONTRACT-mcp.md`、`server/README.md`。卡片：W09 视频页（Antigravity）、C11 一键生成剪映草稿（Cursor）、WK05 实测视频助手（grokbot）。

## 自测

- `pytest` 82 个全过（mcp 1.x、2.x 各跑一遍）。新增覆盖：MP3、WAV 时长、配音拉长镜头、字幕切分和留空、画面/配音类型校验、送审违禁词拦截、锁定、退回必填意见、撤回、取消、初剪包内容、成片类型校验、素材库只出成片不出过程素材、AI 新建脚本和交配音（Hermes 目录里的本机文件）、用素材库图当画面、送审后 AI 改不了。

## 为什么剪映草稿交给 Cursor

剪映草稿用开源库 pyJianYingDraft（Apache-2.0，4.8k 星，支持到剪映 10.8）生成最稳。但生成的草稿要在装了剪映的 Windows 电脑上打开才能确认对不对，这边的云端环境做不了这个检查，所以写成 C11 交给你电脑上的 Cursor 做和测（只开剪映，不碰 Hermes 窗口）。没有 C11 之前，初剪包已经能用：拖进剪映、导入字幕就行。

## 没做 / 待确认

- 配音声音：Edge TTS 免费但声音选择有限；要更自然的配音（例如品牌固定的声音）需要付费服务，要你们定。
- 短视频平台直接发布不做（方案定了不代发）。
- M4A、OGG 配音读不出时长，按写的时长算；剪辑在剪映里会看到实际长度。
