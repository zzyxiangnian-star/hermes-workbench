# C09 完成报告：设计页后端和设计助手（生图）

做的人：Claude（用户说“继续”）。第二期里品牌活动工作台的“设计”页和生图 Bot。

## 做了什么

- **设计需求单**：类型（主图、详情页、海报、横幅、视频封面）、尺寸、图上文案、需求说明、参考图、截止日、关联活动和商品。状态 待接单 → 设计中 → 待评审 → 已定稿，可取消；退回修改必须写说明，自动进入下一轮。每一步记处理记录，过了截止日标逾期。
- **候选稿和评审**：设计师或设计助手交稿后自动进入待评审；每轮从 A 开始编号，可以并排对比；批注可以钉在图上某个位置（x、y）；定稿前图上文案先过违禁词，有必须改的词不让定稿。
- **素材库**：定稿自动进素材库，也能直接上传 Logo、旧图等；按品牌、商品、活动、类型、标签找。文件存本机，按内容去重，类型按文件头判断（改扩展名的文件进不来），单个文件默认 50 MB 以内。
- **设计助手 Bot**（`bots/design-assistant/`）：读需求单、商品资料卡和品牌规范，用 Hermes 自带的 `image_generate` 出初稿，再用新工具 `wb_add_design_candidate` 把图交回需求单。只能交候选稿，不能定稿、退回或删除；每轮最多交 8 张。交图支持 https 链接（只允许公网地址）、data 链接和 Hermes 目录里的本机文件（其他目录读不了）。
- **迁移 c09**：新表 design_requests、assets、design_comments；与模型比对一致，升级、降级再升级都验证过。
- **演示数据**：3 张需求单（待评审带两张候选稿和一个图上批注、待接单、已定稿）和素材库里的两张 Logo，图都是纯色占位图；演示素材放在 `data/demo-assets`，demo.bat 已带上。
- 文档：新增 `docs/CONTRACT-design.md`，更新 `CONTRACT-mcp.md`、`server/README.md`、`env.example.bat`。界面卡 W08、grokbot 实测卡 WK04 已写好。

## 没做 / 待确认

- **生图服务选哪家**：Hermes 的 `image_generate` 默认走 FAL（境外服务，要 FAL_KEY）。客户在国内，速度、费用和合规要评估，可能要换国内的生图服务（需要写 Hermes 生图插件）。这个要你和客户定。
- 生图模型写中文字不稳，设计助手的设定是只留位置、不把文案画进图里，由设计师排字。
- 短视频（脚本、配音、剪映初剪）是第三期，这次没做。
- 缩略图没做：页面直接缩放原图，素材多了以后再加。
