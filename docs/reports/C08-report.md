# C08 完成报告：客户页后端（客户档案、B 端询盘和报价、会员分层、批量跟进）

做的人：Claude（用户说“继续”）。第二期“客户”页里不依赖平台授权的部分。

## 做了什么

- **客户档案**：导入订单时按手机号自动建档（去掉 +86、跨店铺合并）；企业客户可手动建，或在新建询盘时按手机号 / 公司名自动建。每个客户算出累计订单（按订单号去重、退款关闭的不算）、金额、首单和最近一单、最近买的商品、在哪些店买过。
- **会员分层**：新客（30 天内只买过 1 单）、复购（2 单及以上）、沉睡（最近一单在 90 天前）、询盘未成交（超过 7 天没跟进）。每次现算，不存表。“加购未买”要平台接口，第二期再做。
- **B 端询盘**：记录渠道、公司、联系人、内容和提到的商品；状态 新询盘 → 已回复 → 已报价 → 成交 / 丢单（丢单必须写原因），每步记处理记录；旁边的资料栏直接给出这些商品的资料卡和各店售价库存。
- **报价单**：按行填商品、数量、单价，自动算合计、编号 `BJ日期-流水`、有效期默认 15 天；生成 Markdown 正文给销售复制或打印。出报价后询盘自动变“已报价”。
- **批量跟进**：选分层和渠道、写话术（可用 {称呼}{最近商品}{店铺} 等占位符），生成每个人的话术。企微渠道只给加了企微的人，其余记“跳过”。主管审核时先过违禁词；审核后才能导出名单、逐个标“已发”。**系统不自动发任何消息。**
- **电商助手**：5 个新工具（客户列表含分层人数、客户详情、询盘列表、询盘详情含资料卡、给询盘写备注）。姓名留姓、手机留前三后四，询盘原文里的手机号也打码。AI 不能出报价、改状态、建或审跟进。
- **迁移 c08**：新表 customers、inquiries、quotes、followups、followup_targets，orders 加 customer_id；与模型逐项比对一致，升级、降级再升级都验证过。
- **演示数据**：约 50 个客户（复购 5、沉睡 8、约三分之一加了企微）、3 条询盘（含一张 40 台空调的报价单、一条丢单）、一个待审核的“沉睡客户唤醒”跟进任务。手机号都是 100 号段假号。
- 文档：新增 `docs/CONTRACT-customers.md`，更新 `CONTRACT-mcp.md`、`server/README.md`、电商助手的 SOUL 和工具白名单。界面卡 W07 已写好。
