# C05 完成报告：品牌活动“内容”页后端

做的人：Claude（用户说“继续”）。同一轮还补了 W03 要的三处商品接口、让后端在 `mcp` 2.x 下也能启动（提交 C04.1）。

## 做了什么

- **数据表**（迁移 `c05`）：`contents` 稿件、`content_variants` 平台版本、`content_versions` 版本快照、`content_comments` 批注。
- **接口**（`app/api/contents.py`）：稿件增删改查和筛选（状态、品牌、活动、平台、关键词）；一稿多平台；送审、撤回、通过、退回（必须写原因）、标记已发布（可按平台记链接）；批注（可带引用原文和字符位置）；版本快照和版本对比（先按行、再按字）。
- **送审前自动合规检查**：主稿和每个平台版本有 must 级违禁词就拦下，并列出要改的词。复用 C04 的违禁词库。
- **品牌助手**：MCP 新增 3 个工具（稿件列表、稿件详情含合规结果、新建草稿）。`wb_create_draft` 只能新建，作者固定“品牌助手”、状态固定草稿，没有改状态的参数；送审、审核、发布只能人在工作台做。品牌助手 Bot 的白名单和 SOUL.md 已更新。
- **文档**：`docs/CONTRACT-brand.md` 加了“内容（C05）”一节，`docs/CONTRACT-mcp.md` 补了新工具。
