# C07 完成报告：安装页后端（啄木鸟预约）

做的人：Claude（用户说“继续”）。这是第二期里不依赖平台授权、先能做的部分。

## 做了什么

- **订单导入**：`POST /api/import/orders`，认淘宝、京东等导出表的常见列名，处理 `="订单号"` 这类导出格式；报表文件夹也能自动认出订单表。迁移 `c07` 加了 `orders`、`install_orders` 两张表，并让导入记录允许 `orders`（SQLite 和 PostgreSQL 分别处理了 CHECK 约束）。
- **自动生成工单**：买了“需安装”商品（商品资料卡勾选）的订单自动建工单；订单关闭或退款的不建，已有的未完工工单自动取消；改资料卡后自动补。
- **工单流转**：待预约、已预约（必须填预约时间）、已完工、异常（必须写原因）、已取消；每一步记处理记录（谁、何时、做了什么）；待预约超过 48 小时标超时。
- **给服务商和顾客**：导出预约表（CSV，Excel 直接打开）交给啄木鸟；预约后生成给顾客的通知文字，由客服复制发送，系统不自动发。
- **电商助手**：3 个新工具（工单列表、详情、追加备注）。**顾客姓名、手机、地址发给 AI 前一律打码**（姓名留姓、手机留前三后四、地址留到区县）；工作台页面和导出表是完整信息，只在本机。
- **演示数据**：加了最近 3 天的订单和约 15 张工单（已预约、异常、带备注的各一张），手机号用 100 号段，不是真号码。
- 文档：新增 `docs/CONTRACT-installs.md`，更新 `CONTRACT-mcp.md`、`server/README.md`、电商助手的 SOUL 和工具白名单。
