## 活动页
- **页头操作区**：主按钮“新建活动”。
- **月历**：默认本月，左右切月、“今天”。每个活动是一条横跨起止日期的色条，颜色按 `phase`（即将开始 / 进行中 / 已结束 / 已取消），用 Hermes 的语义色变量，不写死颜色。色条上是活动名，悬停 Tip 显示品牌、日期、任务完成 x/y。请求用 `GET /api/campaigns?date_from=月初&date_to=月末`。
- 月历下方或右侧：同一时间段的**列表**（名称、品牌、类型、日期、任务进度条、阶段 Badge），可按品牌筛选。窄窗口时只显示列表。
- **新建活动弹窗**：名称、品牌（下拉，来自 `/api/shops` 的品牌去重，也可手填）、类型、起止日期、目标销售额、预算、目标说明、“按类型套用任务清单”开关（默认开，旁边列出将生成的任务，来自 `/api/campaign-templates`）。
- **活动单抽屉**（点色条或列表行）：
  - 基本信息可编辑，状态用 SegmentedControl（筹备 / 进行中 / 已结束 / 已取消）。
  - 任务清单：勾选完成、改负责人和截止日、加任务、删任务（删前 ConfirmDialog）。
  - “复盘”分栏：调 `/review`，指标用紧凑的“数值 + 环比箭头”行，不做大卡片；目标完成率、预算使用率用细进度条；分店铺表；`days_with_data < days` 时显示提示；底部“复制复盘文字”（复制 `markdown`）。
  - “交给品牌助手”按钮：复制一句提示到剪贴板，例如“帮我写活动『双 11』的复盘结论，活动 id 是 3”，并提示用户去品牌助手对话里粘贴。（第一版不自动打开 Bot 对话。）

## 资料页
三个分栏（SegmentedControl 或 Tabs，照 Hermes 原生）：
- **商品资料卡**：列表（名称、编码、品牌、是否需安装、几个店铺在卖），搜索和品牌筛选；点开 CardDrawer 编辑：卖点（可增删的一行一条）、参数、常见问题（问 / 答成对增删）、需安装开关、备注；下面只读显示各店铺的售价、库存、活动（`listings`）。新建时编码必填，保存后不能改。
- **品牌规范**：左边品牌列表，右边表单：语气、品牌色（色块 + 色值，可增删）、字体、Logo 用法、其他注意。保存用 PUT。
- **违禁词**：表格（词、级别、分类、替换建议、启用开关），加词、删词；上方是 **CompliancePanel**：一个多行输入框 + “检查”按钮，结果在原文上用下划线标出命中位置（must 用 error 色，warn 用 warn 色），悬停显示分类和建议，旁边列出命中清单。

## 参考项目

- [FullCalendar](https://github.com/fullcalendar/fullcalendar)（MIT）：月视图里多日事件色条的排布算法（同一周内多条活动怎么分行不重叠）。**不引入这个库**，只借算法，拷代码就记进 `THIRD_PARTY.md`。
- [Plane](https://github.com/makeplane/plane)（AGPL-3.0）：周期和任务进度条的交互，只看不拷。
- [Chatwoot](https://github.com/chatwoot/chatwoot)（MIT）：设置页里标签 / 词库这类小表格的增删交互。
