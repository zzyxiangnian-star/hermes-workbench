## 顺带（后端已好）
- **备份**：工作台设置（插件里改后端地址的那个地方）加一块“数据备份”：显示备份目录和最近几份快照（`GET /api/backup`，返回 `{dir, snapshots:[{name, bytes}]}`，新的在前），一个“立即备份”按钮（`POST /api/backup`，返回 `{database, assets_copied, …}`，成功后提示“已备份：文件名，新复制 N 个素材”）。说明一句“每天 12:30 自动备份，位置可在 env.bat 里改”。
- **版本号**：同一块里显示后端版本（`GET /api/health` 的 `version`）。

## 背景
视频页管短视频的“写分镜 → 配音配画面 → 审核 → 下载初剪包到剪映精修 → 交成片”。接口见 `docs/CONTRACT-video.md`，**以它为准**。预览数据用 `server\scripts\demo.bat`（2 个项目：一个已通过、一个写脚本中）。品牌活动工作台加一个分页“视频”（放在“设计”后面）。

## 页面

### 列表
- 筛选：SegmentedControl（未完成 / 待审核 / 已完成 / 全部）、品牌、活动、搜索。
- 卡片：封面（`cover`，竖版按 9:16 显示）、标题、平台、画幅、总长、镜数、缺画面 / 缺配音的数量（warn 色）、状态 Badge。
- 主按钮“新建视频”：标题、品牌、平台、画幅、商品编码、活动、说明。

### ScriptEditor（全宽，左上返回）
- 顶部：标题、状态、总长；右侧按状态的操作：写脚本中“送审”（`compliance_failed` 时把违禁词列在下方，用 `text-destructive`）、待审核“通过”“退回”（必填意见）“撤回”、已通过“下载初剪包”“下载字幕”“交成片”（上传 MP4）、任何未完成状态“取消”。
- 分镜表：一镜一行（ShotRow），列：镜号、画面缩略图（点击换图：上传或从素材库选，素材库用 `/api/assets`）、画面说明、口播、字幕（默认显示“同口播”灰字，可以改，可切换“不要字幕”）、时长（写的 / 实际，实际比写的长时提示“按配音拉长”）、配音（播放按钮 + 上传），备注。
- 可以拖动排序、插入、删除镜头；改动先在本地，点“保存分镜”调 `PUT /shots`（离开页面有未保存改动时 ConfirmDialog）。非写脚本状态整张表只读。
- 口播输入框下方实时显示估计时长（按每秒 4.5 个字）。
- 右侧栏（可拖动分割线）：审核记录（`events`，退回意见醒目显示）、违禁词检查、背景音乐上传。

### Preview（简易预览）
- 按时间线依次显示每镜画面（图片铺满、视频静音播放），同时播放这一镜配音，底部叠字幕。只用浏览器自带的 `<img>`、`<video>`、`<audio>`，不做真正的合成。
- 有播放 / 暂停和镜头进度条。

## 视觉规范
同前：只用 Hermes 的 CSS 变量和 SDK 组件，错误色 `text-destructive`。分镜表参考 Hermes 设置页的表格密度，不要做成大卡片；竖版缩略图宽 48px。
