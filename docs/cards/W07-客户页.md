# W07 电商工作台：客户页（接 C08 后端）

> 发给 Antigravity 里的 Gemini。在 `F:\工作台开发\hermes-workbench` 工作，先 `git pull`。只动 `plugin/`。W06 交回并审查后再开始。
> 不要打开或操作你电脑上的 Hermes 窗口，实测交给 grokbot。

## 背景
客户页有三块：会员（分层和批量跟进）、B 端询盘（记录、报价）、客户档案。接口见 `docs/CONTRACT-customers.md`，**以它为准**。预览数据用 `server\scripts\demo.bat`（约 50 个客户、3 条询盘、1 个待审核的跟进任务）。

## 交付文件
```
plugin/src/api/customers.ts                     ← 请求函数和类型
plugin/src/pages/customers/CustomersPage.tsx    ← 页面和三个子标签
plugin/src/pages/customers/CustomerDrawer.tsx   ← 客户抽屉
plugin/src/pages/customers/InquiryView.tsx      ← 询盘详情（左内容右资料栏）
plugin/src/pages/customers/QuoteDialog.tsx      ← 出报价单
plugin/src/pages/customers/FollowupView.tsx     ← 跟进任务（新建、审核、逐个标记）
docs/reports/W07-report.md
```
`modules/ecommerce.tsx` 里“客户”分页渲染 `CustomersPage`；徽标用 `/api/customers/segments` 的 `open_inquiries`（60 秒刷新，失败不显示）。

## 页面
页面内用 SegmentedControl 切三块：**会员 / 询盘 / 全部客户**。

### 会员
- 顶部四张分层卡（新客、复购、沉睡、询盘未成交）：人数 + 规则（`rule`，悬停 Tip）。点卡片 = 下面列表按该层筛选。
- 列表：姓名、手机、累计单数、累计金额、最近一单日期和商品、店铺、企微（已加 / 未加）、分层 Badge。点行开 CustomerDrawer。
- 右上主按钮“批量跟进”：选分层（默认当前选中的）、渠道、名称、话术（多行输入，下方一排占位符小按钮，点一下插入到光标处）。提交后进入 FollowupView。
- 下方“跟进任务”小节：列出任务（名称、分层、渠道、状态 Badge、待发 / 已发 / 跳过数），点开 FollowupView。

### FollowupView（全宽视图，左上返回）
- 草稿：可改话术（改完重新生成，列表刷新）；“审核通过”按钮（报 `compliance_failed` 时把违禁词显示在话术框下方，用 `text-destructive`）；“删除”（ConfirmDialog）。
- 已审核：每行显示客户、手机、生成好的话术、“复制”按钮（复制话术）、“已发”/“跳过”按钮；顶部“导出名单”下载 CSV、“取消任务”。
- 跳过的行灰显并写原因（“未加企业微信”）。
- 提示条一句话：“系统不会自动发送，请复制到企业微信 / 平台客服里发，发完点已发。”

### 询盘
- 列表：公司、联系人、渠道、内容摘要、状态 Badge、`stale` 时显示“超过 7 天未跟进”（warn 色）、负责人、更新时间。筛选：未关闭（默认）/ 全部 / 各状态，搜索。
- 主按钮“新建询盘”：渠道、公司、联系人、手机、内容、商品编码（可多个，输入时从商品资料卡里搜，`GET /api/product-cards?q=`）、负责人。
- 点行 → InquiryView（全宽视图）：左边是询盘原文、备注、处理记录、报价单列表；右边资料栏（可拖动分割线）是 `/inquiries/{id}/products` 的资料卡（卖点、参数、FAQ、各店售价和库存），`missing` 的编码列出来并提示“还没有资料卡”。底部按状态给操作：已回复、出报价单、成交、丢单（必填原因）、加备注。
- QuoteDialog：可增删的明细行（商品编码可从询盘里的商品一键带入名称和天猫售价作默认单价）、数量、单价、备注，实时算金额和合计；有效期（默认 15 天后）、说明。提交后显示报价单正文（Markdown 渲染），带“复制”和“打印”（`window.print()`，只打印报价单区域）。

### 全部客户
- 列表同会员，多一个类型筛选（会员 / 企业）和“新建企业客户”按钮。
- CustomerDrawer：基本信息（可改名称、公司、企微勾选、标签、备注）、累计数据、订单列表、询盘列表（点击跳到 InquiryView）。

## 视觉规范
同前：只用 Hermes 的 CSS 变量和 SDK 组件，错误色 `text-destructive`。分层卡照 W03 汇总卡的样子，不要做大色块；报价单正文用 Hermes 的 Markdown 渲染样式。

## 参考项目
- [Chatwoot](https://github.com/chatwoot/chatwoot)（MIT）：联系人列表、联系人侧栏和“分组 → 批量操作”的交互。
- [Twenty](https://github.com/twentyhq/twenty)（AGPL，只看设计不拷代码）：客户列表和详情的信息分组。
- [Invoice Ninja](https://github.com/invoiceninja/invoiceninja)（Elastic License，只看设计不拷代码）：报价单明细行增删和实时合计。
- Hermes 看板插件：抽屉、多选和全宽视图的返回方式。
