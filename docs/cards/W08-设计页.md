# W08 品牌活动工作台：设计页（接 C09 后端）

> 发给 Antigravity 里的 Gemini。在 `F:\工作台开发\hermes-workbench` 工作，先 `git pull`。只动 `plugin/`。W07 交回并审查后再开始。
> 不要打开或操作你电脑上的 Hermes 窗口，实测交给 grokbot。

## 背景
设计页管“提需求 → 设计师（或设计助手 AI）交稿 → 评审批注 → 定稿 → 进素材库”。接口见 `docs/CONTRACT-design.md`，**以它为准**。预览数据用 `server\scripts\demo.bat`（3 张需求单：待评审带两张候选稿和一个图上批注、待接单、已定稿；素材库 3 张图，都是纯色占位图）。

图片地址是后端返回的 `url`（`/api/assets/{id}/file`），前面拼上后端地址，和其他接口用同一个基地址函数。

## 交付文件
```
plugin/src/api/design.ts                       ← 请求函数和类型（含 multipart 上传）
plugin/src/pages/design/DesignPage.tsx         ← 设计页（需求 / 素材库 两个子标签）
plugin/src/pages/design/RequestDialog.tsx      ← 新建、编辑需求单
plugin/src/pages/design/ReviewView.tsx         ← 评审视图（全宽）
plugin/src/pages/design/PinLayer.tsx           ← 图上批注点
plugin/src/pages/design/AssetGrid.tsx          ← 素材网格（素材库和参考图共用）
docs/reports/W08-report.md
```
`modules/brand.tsx` 里“设计”分页渲染 `DesignPage`；徽标用 `/api/design-requests/summary` 的 `needs_action`（60 秒刷新，失败不显示）。

## 页面

### 需求（默认子标签）
- 顶部汇总一行：待接单、设计中、待评审、逾期（warn 色）。
- 筛选：SegmentedControl（未完成 / 待评审 / 已定稿 / 全部）、品牌、类型、活动下拉、搜索。
- 列表用卡片网格：封面（`cover`，没有就显示类型图标）、标题、类型和尺寸、截止日（逾期标红用 `text-destructive`）、负责人、状态 Badge、候选稿数、未解决批注数。
- 主按钮“提需求”→ RequestDialog：标题、类型、品牌、活动、商品编码（从资料卡里搜）、尺寸（可加多个，输入 800x800）、图上文案（下方实时显示违禁词检查，调 `/api/compliance/check`，防抖 500ms）、需求说明、截止日、负责人、参考图（拖拽上传，提交需求单后逐张传 `role=reference`）。
- 点卡片 → ReviewView。

### ReviewView（全宽，左上返回）
- 左栏（可拖动分割线）：需求信息（类型、尺寸、文案及违禁词检查结果、说明、截止日、商品资料卡摘要、参考图缩略图）、处理记录。
- 中间：按轮次分组的候选稿，默认显示当前轮；可勾选 2–4 张并排对比（同样高度，下面写字母、来源“AI 生成”小标、宽高）。点一张进入单图大图模式。
- 大图模式：在图上点一下 → 弹出小输入框写批注，存 `x、y`（相对图片宽高的 0–1）；已有批注显示为编号小圆点，悬停看内容，点开可标已解决。右侧列出这张图的批注。
- 底部操作按状态：
  - 待接单：“接单”（变设计中，by 填当前用户名或“设计师”）、“取消”。
  - 设计中 / 待评审：“上传候选稿”（可多选文件）。
  - 待评审：“定稿”（先勾选候选稿，`compliance_failed` 时在按钮旁显示违禁词）、“退回修改”（必填说明）、“取消”。
  - 已定稿：显示定稿图，“下载原图”（`?download=true`）。
- AI 交的稿显示提示词（折叠），方便设计师照着改。

### 素材库
- 筛选：品牌、商品编码、活动、类型、搜索（文件名、标签、说明）。
- 网格：缩略图（`object-fit: contain`，非图片文件显示类型图标）、文件名、宽高、标签。点开抽屉：大图、信息、可改标签和说明、下载；`library` 可以删除（ConfirmDialog），`final` 不显示删除。
- 主按钮“上传素材”：拖拽多文件，填品牌、商品编码、标签。

## 视觉规范
同前：只用 Hermes 的 CSS 变量和 SDK 组件，错误色 `text-destructive`。图片区背景用 Hermes 的次级背景色，不要纯白或纯黑；批注点用主题强调色，带白色描边保证在任何图上都看得见。

## 参考项目
- [Excalidraw](https://github.com/excalidraw/excalidraw)（MIT）：画布上点选、悬停提示的交互细节。
- [Penpot](https://github.com/penpot/penpot)（MPL-2.0，只看设计不拷代码）：设计稿上的评论点、评论列表和“已解决”。
- [Immich](https://github.com/immich-app/immich)（AGPL，只看设计不拷代码）：素材网格、按条件筛选、大图查看器的排布。
- Hermes 看板插件：全宽视图和抽屉的切换方式。
