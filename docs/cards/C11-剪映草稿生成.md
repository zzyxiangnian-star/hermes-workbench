# C11 一键生成剪映草稿（接 C10 时间线）

> 发给 Cursor。在 `F:\工作台开发\hermes-workbench` 工作，先 `git pull`。只动 `server/`。**需要在装了剪映专业版的 Windows 电脑上做和测**（只开剪映看草稿，不要打开或操作 Hermes 窗口）。

## 背景
C10 已经做好短视频项目：每镜的画面、配音、字幕和起止时间都在 `GET /api/video-projects/{id}/timeline` 里（说明见 `docs/CONTRACT-video.md`），也能下载初剪包手动在剪映里摆。这张卡让剪辑点一下就在剪映的草稿列表里出现一个摆好的草稿：画面在主轨、配音在音频轨、字幕在文本轨、背景音乐在第二音频轨，剪辑直接精修。

用 [pyJianYingDraft](https://github.com/GuanYixuan/pyJianYingDraft)（Apache-2.0，可以用）。它支持新版剪映（README 写测到 10.8）的草稿生成；**不要用**它的自动导出（剪映 7+ 不支持，而且要操作剪映窗口）。

## 交付
```
server/pyproject.toml          ← 加可选依赖 [project.optional-dependencies] video = ["pyJianYingDraft>=0.3"]，记在 THIRD_PARTY.md
server/app/jianying.py         ← build_draft(project, draft_root) -> 草稿名
server/app/api/video.py        ← 新接口（见下）
server/tests/test_jianying.py  ← 没装 pyJianYingDraft 时自动跳过（pytest.importorskip）
docs/CONTRACT-video.md         ← 补一节“剪映草稿”
docs/reports/C11-report.md
```

## 要求
1. 草稿目录：环境变量 `WB_JIANYING_DRAFT_DIR`；没设时按剪映默认位置找（`%LOCALAPPDATA%\JianyingPro\User Data\Projects\com.lveditor.draft`），找不到返回 400 `draft_dir_not_found`，提示在 env.bat 里设置（同时更新 `scripts/env.example.bat`）。
2. 接口 `POST /api/video-projects/{id}/jianying-draft` `{by}`：只限 `approved`（否则 409 `not_approved`）；没装 pyJianYingDraft 返回 501 `video_extra_missing`（提示 `pip install -e .[video]`）。返回 `{draft_name, draft_path, shots, duration}`，并在项目 `events` 记一条“生成剪映草稿”。
3. 草稿名：`{项目编号}-{标题}`，非法文件名字符换成 `_`；同名已存在时加 `-2`、`-3`，**不覆盖**剪辑已经在改的草稿。
4. 素材先复制进草稿文件夹下的 `materials/`（文件名用初剪包的命名 `01_画面.png` 等），草稿里引用复制后的路径，这样工作台素材目录搬走也不影响。
5. 画幅按 `timeline` 的 `width/height` 建草稿。每镜：
   - 画面：图片按这一镜的 `duration` 铺满；视频从头截这一镜的时长，素材不够长就放到结束为止（不要报错）。没画面的镜留空。
   - 配音：放在这一镜的 `start`。
   - 字幕：用 C10 的切分结果（`app.video._subtitle_lines` 和 SRT 同一套时间），放屏幕下方，字号适中，白字黑描边。
   - bgm：铺满全片，音量 25%，结尾 1 秒淡出。
6. 不加转场、特效、花字（都留给剪辑）。

## 测试
- 单元测试：用 C10 测试里的方式造一个项目（PNG、WAV 素材），生成到临时目录，检查草稿文件夹、`materials/`、草稿 JSON 里有 4 条轨道和正确的片段数、起止时间（微秒）。
- 实测（必须）：在你这台电脑的剪映里打开生成的草稿，确认画面、配音、字幕、bgm 的位置和时长都对。用演示数据：`server\scripts\demo.bat`，对“木屿夏凉被 15 秒种草”（已通过）调接口。截图：剪映时间线全貌、字幕轨特写。
