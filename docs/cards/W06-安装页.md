# W06 电商工作台：安装页（接 C07 后端）

> 发给 Antigravity 里的 Gemini。在 `F:\工作台开发\hermes-workbench` 工作，先 `git pull`。只动 `plugin/`。W05 已审查通过，可以开始。
> 不要打开或操作你电脑上的 Hermes 窗口，实测交给 grokbot。

## 先修（grokbot WK03 在真实 Hermes 里发现的，先做这几条再做安装页）
1. **刷新丢页面**：商品页按 Ctrl+R 后变成 `#/` 新会话，两次都一样。W03 用 sessionStorage 记了最后的路由，但没生效。先查清是宿主在插件加载前就把地址改成 `#/`，还是插件恢复的时机不对；能在插件侧补就补（例如插件模块加载时读 sessionStorage，地址是 `#/` 且记录在 1 分钟内就跳回去），补不了就在报告里写清楚原因，交给宿主侧处理。
2. **后端断开或恢复时整页报 insertBefore 错误**：和 W05 修的 HeaderActions 是同一类问题。确认 W05 的修法已经覆盖；没覆盖就把断开提示也改成不移动 DOM 的写法。
3. **断开提示加两个按钮**：“重试”（立刻重新请求）和“更改地址”（打开设置里的后端地址）。
4. **问题抽屉里加“重新打开”**：已处理、已忽略的问题能改回 open（`PATCH /api/issues/{id}`，`status: open`）。另外后端已改：导入后同一商品同一规则又不满足时，会重开原来那条并在备注里写“导入后检查仍不满足，已重新打开”，不再新开一条重复的。
5. **窄窗口布局**：对照 WK03 截图（`docs/reports/WK03/` 里窄窗口那几张，如果没有就按 360px 面板宽自查）修掉挤压和溢出。
6. 内容页小处：审核记录里平台名后端已改成中文（“已发布到小红书”），界面不用再转。

工作台路由 id 被宿主当成会话 id 去查、产生约 50 条 404，这是 Hermes 宿主的行为，插件不用改，报告里记一句就行。

## 背景
客户卖空调、热水器等需要上门安装的家电，安装由啄木鸟负责。安装页把“需要安装的订单”变成工单，客服在这里约时间、跟进异常、通知顾客。接口见 `docs/CONTRACT-installs.md`，**以它为准**。预览数据用 `server\scripts\demo.bat`（含约 15 张工单）。

## 交付文件
```

plugin/src/pages/installs/InstallsPage.tsx   ← 安装页
```

`modules/ecommerce.tsx` 里“安装”分页渲染 `InstallsPage`；徽标用 `/api/installs/summary` 的 `needs_action`（60 秒刷新，失败不显示）。

## 页面
- **页头操作区**：主按钮“导入订单”（复用 W03 的 ImportDialog，加一个“订单”类型，调 `/api/import/orders`，结果里显示“新建工单 N 张”）；次要按钮“导出待预约”（`POST /api/installs/export`，下载 CSV；有勾选时只导勾选的）。
- **顶部汇总一行**：待预约 N（其中超时 M，用 warn 色）、已预约 N、异常 N（destructive 色）、今天已完工 N。
- **筛选**：SegmentedControl（待处理 = 待预约 + 异常 / 已预约 / 已完工 / 全部）、店铺下拉、只看超时开关、搜索（订单号、商品、收货人、手机）。
- **列表**（平铺行，可多选）：工单号、商品、收货人和手机（完整显示，本机用）、地址（截断，悬停 Tip 全文）、买家留言（有就显示一个小图标，悬停看全文）、付款时间、状态 Badge、超时标记、预约时间。
- **点行 → InstallDrawer**：订单信息、收货信息（手机号旁边有“复制”）、买家留言、备注、处理记录时间线（`events`），底部按状态显示操作：
  - 待预约：“填预约”（BookDialog：日期时间、师傅、服务商单号）、“标异常”（必填原因）、“取消”（ConfirmDialog）。
  - 已预约：“已完工”、“改预约”（BookDialog）、“标异常”、“复制预约通知”（`GET /notice`，复制到剪贴板并提示“已复制，请粘贴到旺旺/京东咚咚发给顾客”）。
  - 异常：“重新预约”、“退回待预约”、“取消”。
  - 任何状态都能加备注。
- 预约时间用本机时区输入，提交时带 `+08:00`。
