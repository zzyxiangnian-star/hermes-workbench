# W10 电商工作台：经营页（接 C02 后端）

> 发给 Antigravity 里的 Gemini。在 `F:\工作台开发\hermes-workbench` 工作，先 `git pull`。只动 `plugin/`。
> 不要打开或操作你电脑上的 Hermes 窗口，实测交给 grokbot。

## 背景
九页里只有“经营”还是占位（`modules/ecommerce.tsx` 里的 EmptyState），WK08 总测发现的。后端早就好了：总览、趋势、投放列表、投放提醒、投放规则、日报，接口见 `docs/CONTRACT-overview.md`，**以它为准**。演示数据有 4 个店铺 30 天的经营和投放数据、昨天的 3 条投放提醒。

## 交付文件
```
plugin/src/api/overview.ts                    ← 请求函数和类型
plugin/src/pages/overview/OverviewPage.tsx    ← 经营页
plugin/src/pages/overview/Sparkline.tsx       ← 小折线图（自己用 SVG 画，不引图表库）
plugin/src/pages/overview/AlertDrawer.tsx     ← 投放提醒抽屉 + 投放规则
plugin/src/pages/overview/ReportDialog.tsx    ← 日报预览
docs/reports/W10-report.md
```
“经营”分页渲染 `OverviewPage`；徽标用 `GET /api/alerts/summary` 里未处理的“必须处理”数（字段同商品问题汇总，60 秒刷新，失败不显示）。

## 页面
- **页头操作区**：主按钮“看日报”（`GET /api/reports/daily?date=`，ReportDialog 里按 Markdown 显示，带“复制”）；次要按钮“导入经营 / 投放表”（复用商品页的 ImportDialog，类型选经营或投放，调 `/api/import/metrics`、`/api/import/ad-spend`）。
- **筛选一行**：日期（默认不传，后端用最晚有数据的一天；页面上显示它返回的 `date`）、店铺下拉（含“全部店铺”）。
- **指标卡 8 张**（`GET /api/overview`）：访客、订单、销售额、转化率、客单价、投放花费、投放 GMV、ROI。每张：大数字、和前一天比的涨跌（`change`，涨用正常色、跌用 warn 色，持平灰色；ROI、转化率跌超过 20% 用 destructive 色）、下面一条 7 天小折线（`/api/overview/trend?days=7&metric=`）。金额两位小数，比率显示百分比，`null` 显示“—”。
- **趋势区**：选一个指标（SegmentedControl：销售额 / 订单 / 访客 / 投放花费 / ROI），天数 7 / 30，一张大折线图（同一个 Sparkline 组件放大，带横轴日期首尾和最高点数值，悬停显示当天数值）。
- **投放计划表**（`GET /api/ad-spend?date_from=&date_to=`，默认就是当前日期）：店铺、工具、计划、花费、GMV、ROI；有 `has_alert` 的行前面一个 warn 色圆点；按花费倒序。
- **投放提醒**：右上角“投放提醒 N”按钮打开 AlertDrawer：列出 `GET /api/alerts?status=open`，每条可“标已处理”（加备注）、“忽略”（ConfirmDialog），和商品问题抽屉同一套交互（直接复用 W03 的组件最好）；抽屉底部“投放规则”：`GET /api/ad-rules`，改阈值、开关、保存、“立即检查”（`POST /api/ad-rules/run`）。
- 没有任何经营数据时：EmptyState 写“还没有经营数据，导入后台导出的经营表和投放表后显示”，带导入按钮。

## 视觉规范
同前：只用 Hermes 的 CSS 变量和 SDK 组件，错误色用 `text-destructive`。指标卡参考 Hermes 设置页的卡片样式，不要渐变、阴影和大色块。折线只用一种强调色，不要彩虹配色。

## 参考项目
- [Tremor](https://github.com/tremorlabs/tremor)（Apache-2.0）：KPI 卡的数字、涨跌和小折线排布。只看样式，不引入它的包。
- [Plausible](https://github.com/plausible/analytics)（AGPL，只看不拷）：顶部指标卡和下方大图联动的方式。
- Hermes 看板插件：抽屉和规则编辑沿用商品页的做法。
