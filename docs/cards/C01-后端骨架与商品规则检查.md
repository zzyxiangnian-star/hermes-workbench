# C01 后端骨架 + 商品数据与规则检查

> 发给 Cursor。仓库：`git clone https://github.com/zzyxiangnian-star/hermes-workbench`（若 Antigravity 已在 `F:\工作台开发\hermes-workbench` 克隆过，就在同一个文件夹里工作，先 `git pull`）。你只动 `server/` 目录。

## 背景
我们给一个电商客户做两个装在 Hermes 里的工作台（方案：https://claude.ai/artifact/U2LDv6JTx2GPgfMddu3eSQ ）。界面由 Antigravity 做，后端由你做。
第一期还没拿到天猫、京东、拼多多的接口授权，所以**商品数据先从客户导出的报表（Excel/CSV）导入**，再按规则每天检查，只把异常列出来，代替运营每天人工检查。
这张卡做后端骨架和“商品”这一页需要的数据与接口。

## 技术选型（照用）
Python 3.12、FastAPI、SQLAlchemy 2（或 SQLModel）、SQLite（以后迁 PostgreSQL，所以不要用 SQLite 特有语法）、openpyxl / pandas 读报表、pytest。依赖写进 `server/pyproject.toml`。

## 数据模型（字段名照用，可以加字段，不要改名）
- `shops`：id、platform（tmall / jd / pdd / douyin）、name、brand
- `products`：id、shop_id、sku（店铺内唯一）、product_code（同一商品跨店铺通用的货号）、title、price、floor_price（底价，可空）、stock、activity（当前报名的活动名，可空）、updated_at
- `rules`：id、kind（见下）、name、params（JSON）、level（must / warn）、enabled
- `issues`：id、product_id、rule_id、level、message（中文，一句话说清问题）、status（open / resolved / ignored）、found_at、resolved_at、note
- `import_runs`：id、file_name、shop_id、rows_ok、rows_failed、errors（JSON）、created_at

## 报表导入
- `POST /api/import/products`：上传 xlsx 或 csv，参数 `shop_id` 和可选的列映射 `mapping`（JSON，报表列名 → 字段名）。不传 mapping 时按常见中文列名自动识别（商品编码/SKU、货号、标题、价格/售价、底价、库存、活动），识别规则写在一处、方便以后加。
- 按 (shop_id, sku) 更新或新建；坏行不中断整个导入，记到 `import_runs.errors`（行号 + 原因）。
- 导入完成后自动跑一次规则检查。

## 规则检查（rules.py）
第一期四种规则，参数放 params：
1. `below_floor`：price < floor_price → must，“售价 189 低于底价 199”
2. `cross_shop_gap`：同一 product_code 在不同店铺的价格差超过 `max_gap_pct`（默认 5%）→ warn，消息列出最低和最高的店铺和价格
3. `low_stock`：stock < `min_stock`（默认 10）→ warn
4. `missing_activity`：`required_activity` 参数非空时，没报这个活动的商品 → warn

- `POST /api/rules/run`：跑全部启用的规则。**同一商品同一规则已有 open 的问题就不重复建**；问题已不再成立的，自动置为 resolved。
- 默认规则在第一次启动时自动写入。

## 接口（全部 JSON，前缀 /api）
- `GET /health`
- `GET /shops`、`POST /shops`
- `GET /products?shop_id=&brand=&q=&has_issue=&page=&page_size=`（分页，返回 total）
- `GET /issues?status=open&level=&shop_id=`；`PATCH /issues/{id}`（改 status 和 note）
- `GET /issues/summary` → 各店铺 open 问题数（给左栏徽标用）
- `GET /rules`、`PATCH /rules/{id}`（改 params、enabled）
- `POST /import/products`、`GET /import/runs`
- 错误统一返回 `{ "error": { "code": "...", "message": "中文说明" } }`
- 开 CORS 只允许本机来源；默认只监听 127.0.0.1

## 测试（必须）
- 导入：两张样表都能导入；自动识别列名；坏行被记录而不中断。
- 四种规则各至少一个命中、一个不命中的用例；重复检查不重复建问题；问题消失后自动 resolved。
- 接口：用 FastAPI TestClient 测分页、筛选、PATCH。
