## 背景
内容页是品牌活动工作台的“写稿 → 合规 → 审稿 → 发布”流水线。一篇稿件有一份主稿和若干平台版本（公众号、小红书、抖音……），审稿要能批注、退回、看改了哪里。后端已好，接口见 `docs/CONTRACT-brand.md` 的“内容（C05）”，**以它为准**。品牌助手可以把文案直接存成草稿（作者显示“品牌助手”）。

## 交付文件
```
plugin/src/api/contents.ts                    ← 稿件、版本、批注、流转的请求函数和类型
plugin/src/pages/contents/ContentsPage.tsx    ← 列表页
plugin/src/pages/contents/ContentEditor.tsx   ← 编辑页（主区域整页，不是抽屉）
plugin/src/pages/contents/CommentsPanel.tsx   ← 右侧批注栏
plugin/src/pages/contents/VersionsDialog.tsx  ← 版本历史和对比
docs/reports/W05-report.md
```
`modules/brand.tsx` 的“内容”页渲染 `ContentsPage`；徽标显示送审中的稿件数（60 秒刷新，失败不显示）。

## 列表页
- 页头主按钮“新建稿件”（弹窗：标题、品牌、类型、关联活动、要做的平台多选）。
- 状态 SegmentedControl：全部 / 草稿 / 送审中 / 已通过 / 被退回 / 已发布；平台、品牌、活动下拉；搜索。
- 平铺行：标题、类型、平台小图标、关联活动、作者（“品牌助手”写的加一个小 Badge）、状态 Badge、未解决批注数、更新时间。点行进入编辑页。

## 编辑页
- 顶部：返回、标题（可直接改）、状态 Badge、版本号、流转按钮（按状态显示：送审 / 撤回 / 通过 / 退回 / 标记已发布），退回要填原因，标记发布可选平台并填链接。
- 中间：Tabs 切“主稿”和各平台版本，加平台、删平台。正文用多行文本框，字数统计（小红书正文提示 1000 字内、微博 2000 字内，只提示不拦）。被锁定的状态（送审中、已通过、已发布）编辑框只读，并提示“先撤回才能改”。
- 保存：“保存”按钮 + Ctrl/Cmd+S；可选填“改动说明”。离开页面时有未保存修改要 ConfirmDialog。
- 合规：编辑区下方嵌 W04 的 `CompliancePanel`，对当前 Tab 的文字实时检查（停止输入 600ms 后调 `/compliance/check`），命中处下划线标出；送审被拦时把后端返回的 message 显示在流转按钮旁边。
- 右侧批注栏（可拖宽，窄窗口时收成按钮）：选中正文里一段文字后出现“批注”小按钮，带上引用原文和起止位置；批注列表按平台过滤，可标为已解决；`kind="review"` 的系统记录用浅色小字显示（谁、什么时候、做了什么）。
- 版本：“历史版本”打开 VersionsDialog，左边版本列表（版本号、作者、说明、时间），右边对比：选两个版本和平台，调 `/diff`，删除用 `--color-destructive` 底色加删除线，新增用成功色底色，没有的颜色就用 Hermes 现有的语义变量。

## 视觉规范
同 W03、W04：只用 Hermes 的 CSS 变量和 SDK 组件；编辑页的排版参考 Hermes 自己的对话输入区和设置页表单，不做花哨的富文本工具栏。
