> 需要参考 Hermes 源码时，看 `F:\Hermes改造` 里的 hermes-agent 克隆（只读，不要改它）。这张卡**不要求** Hermes 能在你电脑上跑起来。

## 背景
我们要给客户做两个工作台：**电商**（经营、商品、客户、安装）和**品牌活动**（活动、内容、设计、资料）。它们都装进 Hermes 桌面版，入口在左上角，和“会话 | 机器人”并排，变成“会话 | 机器人 | 工作台”。
这张卡只做**框架**：左栏的工作台标签面板、主区域的页面外壳、注册工作台的接口。各分页里的真实功能后面的卡再做，这次每页先放空状态。

## 类型（src/types.ts，原样使用，不要改字段）
```ts
import type { ReactNode } from 'react'
export interface WorkbenchPageDef {
  id: string                 // 'overview'、'products' ……，同一工作台内唯一
  label: string              // '经营'
  codicon: string            // codicon 名称，如 'graph'
  badge?: () => number | undefined   // 待办数，undefined 或 0 时不显示
  render: () => ReactNode
}
export interface WorkbenchDef {
  id: string                 // 'ecommerce'、'brand'
  name: string               // '电商'
  codicon: string
  pages: WorkbenchPageDef[]  // 第一个是默认页
}
export interface WorkbenchLocation { workbench: string; page: string }
```

## registry.ts
- `registerWorkbench(def): () => void`（返回注销函数）、`listWorkbenches(): WorkbenchDef[]`、`useWorkbenches()`（React Hook，注册变化时刷新）。
- 当前位置：`useLocation(): WorkbenchLocation | undefined`、`openPage(loc)`。`openPage` 内部调用一个可注入的导航函数 `setNavigator(fn)`，插件入口里注入 `host.navigate`，预览里注入一个改本地状态的函数。
- 路由路径固定为 `/workbench/<workbench>/<page>`，写一个 `parsePath(path)` 和 `toPath(loc)`。
- 不用任何第三方状态库，用 `useSyncExternalStore` 自己写。

## WorkbenchPane（左栏，宽 260px 左右，会被拉到 200–360px）
- 顶部不需要标题（标签条已经写着“工作台”）。
- 列出所有工作台，每个一行：图标 + 名称 + 右侧展开箭头；展开后缩进列出它的分页（图标 + 名称 + 右侧待办数小徽标）。
- 默认全部展开；展开状态记在 localStorage（读写包 try/catch）。
- 当前所在分页高亮，样式参考 Hermes 侧栏会话列表的选中行；悬停立即变色，离开时淡出（约 100ms）。
- 点分页调用 `openPage`；点工作台名称打开它的第一页。
- 名称过长省略号，被截断时悬停 Tip 显示全名；不要给每一行都加 Tip。
- 没有任何工作台时显示 EmptyState：“还没有安装工作台”。

## WorkbenchPage（主区域）
- 顶部一行：工作台名 / 分页名（面包屑，工作台名是次要文字色，可点回第一页），右侧留一个空的操作区 `<div data-slot="actions" />`，后面的卡往里放按钮。
- 下面渲染当前分页的 `render()`；分页不存在时显示 ErrorState“找不到这个页面”和“回到工作台首页”按钮。
- 左右留白用 Hermes 页面统一的左右边距（看 hermes-agent 源码里 `PAGE_INSET_X` 的值，照用）。

## modules/ecommerce.tsx、modules/brand.tsx
- 电商：经营（graph）、商品（package）、客户（organization）、安装（tools）。品牌活动：活动（calendar）、内容（edit）、设计（symbol-color）、资料（library）。图标名可以换成更贴切的 codicon，报告里写明。
- 每页内容先放 EmptyState：标题是分页名，说明一句这页以后做什么（从方案文档抄，例如商品页“每天按规则检查底价、最低价、活动报名和库存，只列出异常”）。
- 给“商品”和“客户”的 badge 各返回一个假数字，用来看徽标效果。

## plugin.tsx（只写，不要求实测）
照 hermes-agent 里两个内置插件的写法：
- 左栏面板：参考 `apps/desktop/src/plugins/hermes-bots/plugin.tsx` 里 `id: 'pane'` 那段 `ctx.register`，`area: 'panes'`，`data` 里 `placement: 'left'`、`width: '260px'`、`collapsible: true`、`hideOnly: true`、`dock: { pane: 'sessions', pos: 'center', enforce: true }`，标签标题“工作台”，render 返回 `<WorkbenchPane />`。

- 注入导航：`setNavigator(path => host.navigate(path))`；当前位置从 Hermes 的路由读（看 SDK 里有没有读当前路径的接口，找不到就在报告里写明，我来定）。
- 在插件 setup 里注册两个工作台模块。

## 视觉规范（必须遵守）
- 只用 Tailwind 类 + Hermes 的 CSS 变量，**不写死颜色**：文字 `--ui-text-primary/secondary/tertiary/quaternary`，强调 `--ui-accent`，描边 `--ui-stroke-secondary`，选中行和小块背景 `--ui-bg-quinary`，页面背景 `--ui-bg-editor`。`--ui-bg-primary` / `--ui-bg-secondary` 是带强调色的填充，**不要当背景**。
- 组件只能 import `react` 和 `@hermes/plugin-sdk`；SDK 只用 `Button, Badge, Codicon, Tip, EmptyState, ErrorState, cn`。
- 插件运行时不会生成新的 Tailwind 样式：常见基础类（flex、gap-2、px-3、rounded-lg、text-(--ui-…) 等）可以用；任意值类（如 `w-[260px]`）和少见尺寸类不要用，改用 `style={{}}`，或输出一个 `<style>` 块，类名统一加 `wb-` 前缀。
- 字号和行高照 Hermes 侧栏会话列表；圆角 `rounded-lg`；尊重 `prefers-reduced-motion`。
